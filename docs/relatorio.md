# Relatório - Sistema de Biblioteca

## 1. Título

Sistema de Biblioteca

## 2. Descrição

O projeto consiste em um sistema simples de gerenciamento de uma biblioteca.

O sistema permite cadastrar livros e usuários, consultar livros e controlar empréstimos e devoluções.

## 3. Justificativa

O projeto foi desenvolvido com o objetivo de aplicar na prática os conceitos estudados durante o curso de programação.

Através do sistema, é possível utilizar conceitos de programação orientada a objetos, estruturas condicionais, funções e estruturas de repetição.

## 4. Funcionalidades

- Cadastrar livros
- Listar livros
- Buscar livros
- Cadastrar usuários
- Emprestar livros
- Devolver livros

## 5. Temas abordados

- Programação Orientada a Objetos
- Classes
- Objetos
- Listas
- Funções
- Condicionais
- Estruturas de repetição

## 6. Tecnologias

- Python
- Git
- GitHub
- Visual Studio Code

Documentação oficial da linguagem Python.
