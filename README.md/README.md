# Sistema de Biblioteca

## Descrição

Sistema simples de gerenciamento de biblioteca desenvolvido em Python.

O sistema permite cadastrar livros e usuários, consultar livros e controlar empréstimos e devoluções.

## Objetivo

Aplicar na prática conceitos de programação orientada a objetos e estruturas de dados.

## Funcionalidades

- Cadastrar livros
- Listar livros
- Buscar livros
- Cadastrar usuários
- Emprestar livros
- Devolver livros

## Tecnologias

- Python
- Git
- GitHub
- Visual Studio Code

## Conceitos utilizados

- Classes
- Objetos
- Listas
- Funções
- Condicionais
- Laços de repetição
- Programação Orientada a Objetos
