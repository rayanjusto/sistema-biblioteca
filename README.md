# Sistema Biblioteca

Sistema acadêmico desenvolvido para gerenciamento de empréstimos de livros em bibliotecas universitárias.

---

## Objetivo

O projeto tem como objetivo substituir o controle manual de empréstimos por um sistema digital integrado, permitindo melhor organização, rastreabilidade e controle de usuários e livros.

---

## Funcionalidades

- Cadastro de usuários
- Cadastro de livros
- Pesquisa por título, autor e ISBN
- Controle de empréstimos
- Controle de devoluções
- Relatórios de atrasos

---
